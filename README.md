# Morgenpuls (app)

Appen for telefon og PC. Dette repoet er offentlig og inneholder **bare koden**, ingen personlige data.
Dataene ligger i det private repoet `regg92s-hub/morgenpuls` og hentes med en personlig nøkkel som bare
lagres på enheten (kun lesetilgang, kun det ene repoet).

Bygges automatisk av Claude fra kildefilen i det private repoet. Ikke rediger filene her for hånd.
